
# Interactive Quiz Application

## Project Overview
The Interactive Quiz Application is a beginner-friendly web application that tests users' knowledge of computer science and programming through multiple-choice questions.

The application displays one question at a time, checks the selected answer, calculates the final score, and allows users to restart the quiz.

## Objectives
- Develop an interactive quiz using HTML, CSS, and JavaScript.
- Practise DOM manipulation and event handling.
- Use conditional statements and functions to check answers and calculate scores.
- Create a responsive and user-friendly interface.

## Features
- Five multiple-choice questions.
- Four options for each question.
- Immediate feedback for correct and incorrect answers.
- Question progress indicator.
- Automatic score calculation.
- Final results screen.
- Restart Quiz button.
- Responsive design for desktop and mobile devices.

## Technologies Used
- **HTML5:** Defines the structure of the application.
- **CSS3:** Provides styling and responsive layout.
- **JavaScript:** Handles questions, answer checking, navigation, and scoring.

## Project Files
- `index.html` — webpage structure.
- `style.css` — visual design and responsive styling.
- `script.js` — quiz data and application logic.

## How to Run
1. Download or clone this repository.
2. Keep all three application files in the same folder.
3. Open `index.html` in a web browser.
4. Select an answer and click **Check Answer**.
5. Read the feedback and continue through the questions.
6. View your final score and click **Restart Quiz** to play again.

## Concepts Demonstrated
- Variables and arrays.
- Objects and functions.
- Conditional statements.
- Event listeners.
- DOM manipulation.
- Dynamic HTML elements.
- Score calculation and state management.

## Conclusion
This project demonstrates how HTML, CSS, and JavaScript can be combined to build a functional and interactive quiz application.
